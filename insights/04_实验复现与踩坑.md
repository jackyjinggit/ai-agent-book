> 起步版先立方法论与模板，复现内容随实践累积。

## 复现方法（三条铁律）

1. **一轮只改一个变量**（原书第 7 章教训）：对比必须单变量，否则归因无效。
2. **消融验证组件价值**：关掉某组件看性能变化——不确定工具结果回传有没有用，就断掉回传跑一次。
3. **归因到首个错误**：失败后沿「原始字节 → 工具返回 → 序列化 → 模型输入 → 模型输出 → 工具匹配」逐层找第一个分歧，别盯最后一个报错。

## 踩坑清单（先记已有的）

- [ ] **工具结果缺失 → 无限循环**：Agent 调工具后无返回，ReAct 循环卡死——修复：`max_iterations` + 工具返回超时兜底（原书 Ch1/Ch2）。
- [ ] **上下文累积爆炸**：每轮重发全部历史，1k+2k+3k=6k 而非 3k——修复：稳定前缀前移 + 渐进式披露（Ch2）。
- [ ] **KV Cache 与压缩非加性**：单开省 28.3% / 17.5%，合开只省 30%（非 45.8%）——压缩缩短可命中缓存的前缀（Ch7 实测数据）。
- [ ] **评判模型同源 → 评分虚高**：Agent 与评判同家族，钻偏好盲区——修复：多源异构评判（Ch7）。
- [ ] **4/4 当整体结论**：小样本只够决定下一步，不够下结论——先过完整复测再宣称（Ch7）。
