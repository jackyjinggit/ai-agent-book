## 读完这本书，怎么用？

构建自己的 Agent 时，有两件事书里讲透了、但需要配套工具落地：

- **定义边界与降级路径** → [agent-handrail](https://github.com/jackyjinggit)（护栏：为自治 agent 定边界/纪律/降级，对应书第 1、5、9 章安全部分；仓库建设中）
- **检测 Agent 是否在谄媚带偏方向** → [co-agency-integrity](https://github.com/jackyjinggit/co-agency-integrity)（反谄媚/认知免疫工具箱：可复用的检测协议与审计方法，MIT 许可，对应书第 7 章评估）

> 一句话：**读书教你构建 Agent，这两个工具帮你确保它不失控、不骗你。**

## 术语速查（读地图时遇到没见过的词，回来查）

| 术语 | 一句话 |
|---|---|
| ReAct | 推理→行动→观察的循环，Agent 的核心执行模式 |
| KV Cache | 模型内部缓存的注意力键值，前缀一致才命中；决定提示词怎么排 |
| RAG | 检索增强生成：从知识库检索相关内容喂给模型 |
| MCP | 工具调用的标准化协议，把工具定义从框架解耦 |
| Pass@k / Pass^k | k 次尝试至少成一次 / k 次连续全对（能力 vs 可靠性） |
| Rubric | 评分准则表：专家指导、覆盖陷阱、加权、自包含 |
| Goodhart | 「当指标变成目标，它就不再是好指标」——评判模型与 Agent 同源时会钻偏好盲区 |
| RAPTOR / GraphRAG | 层次摘要树索引 / 实体关系图索引，按查询类型选 |
| A2A | Agent-to-Agent 协议，跨组织多 Agent 通信 |
| Harness | 模型之外的工程层（上下文/工具/编排/护栏），Agent 竞争力的主战场 |
