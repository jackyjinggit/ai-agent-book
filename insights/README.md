## 读完这本书，怎么用？

构建自己的 Agent 时，有两件事书里讲透了、但需要配套工具落地：

- **定义边界与降级路径** → [agent-handrail](https://github.com/jackyjinggit)（护栏：为自治 agent 定边界/纪律/降级，对应书第 1、5、9 章安全部分）
- **检测 Agent 是否在谄媚带偏方向** → [co-agency-integrity](https://github.com/jackyjinggit)（反谄媚/认知免疫工具箱：可复用的检测协议与审计方法，MIT 许可，对应书第 7 章评估）

> 一句话：**读书教你构建 Agent，这两个工具帮你确保它不失控、不骗你。**
